title: Vouchers
description: Generate prepaid codes to sell for cash — no transaction fee.
---

Vouchers are **prepaid codes** tied to a hotspot plan. You generate them in a batch, sell them for cash, and the customer redeems the code on your captive portal instead of paying M-Pesa. Great for kiosks, agents, and anyone who prefers cash.

## Generating a batch

1. Go to **Hotspot → Vouchers → Generate**.
2. Choose the **plan** the vouchers unlock.
3. Choose **how many** to create.
4. WIFI.OS generates that many unique codes.

Codes use an unambiguous alphabet (no `0`/`O` or `1`/`I` mix-ups), so they're easy to read off a printed slip.

## Selling and redeeming

- Sell the code however you like — printed slips, over the counter, sent by SMS.
- The customer connects to your Wi-Fi, opens the portal, and enters the code.
- The code is single-use: once redeemed it can't be used again, and you can see when and by whom.

## Keeping track

The vouchers page shows each code's status — **unused**, **redeemed**, or **expired** — and the dashboard shows how many are still in stock and how many were redeemed this week, so you know when to print more.
